# AusnetIT Solutions — Frontend MVP Prototype

Built with:
- HTML5
- Bootstrap 5.3
- CSS3
- Vanilla JavaScript
- GSAP + ScrollTrigger

## Run
Open `index.html` in a browser. No build step is required.

## Included
- Responsive landing page
- Service discovery cards
- Interactive project intake
- Live requirement ticket
- AI clarification simulation
- PM/BA toggle
- Talent request UI
- Security & compliance section
- GSAP entrance, scroll and floating animations

This is a frontend prototype. Backend, Supabase, real LLM, authentication, email and admin workflows are not connected yet.
